# IPTV Channel Player by TAVARC-Code

## Short GitHub description

A Python desktop companion for IPTV playback through VLC, with editable CSV channel lists, M3U import/export, stream checks and a built-in beginner’s guide.

## Project description

I’ve kept the database as CSV so you can see what is in it and change it with familiar tools. Add your own channel URLs, organise them into groups, save the file, and open the enabled channels in VLC. That is the main job.

The app includes a dark interface, TAVARC-Code branding, a separate stream-check report and a small Python plugin hook. The setup launchers check Python and Tkinter, while the same step-by-step guide ships in the folder and opens inside the app. Windows, macOS and Linux are the desktop targets.

There is a limit to what a stream check can tell you. A server replying is useful evidence, but it is not a promise that the channel will play. I’d rather show that distinction than put a cheerful green tick beside a login page.

Python with Tkinter and VLC are required for the source release. Users supply their own authorised streams. Executable builds can be created on each target platform with the included builder; signed installers and bundled channel subscriptions are not supplied.
