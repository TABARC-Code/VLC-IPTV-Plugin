IPTV Channel Player | TAVARC-Code

Extract the whole ZIP first. Read SETUP.md for the full beginner guide.

Windows: double-click Launch Windows.bat
macOS: double-click Launch macOS.command, or use the Terminal steps in SETUP.md
Linux: open a terminal here and run python3 setup_app.py

Install Python 3.10+ with Tkinter and VLC first. No pip packages are required.
The Getting started menu repeats the same guide inside the app.
Sample channels are disabled placeholders: add your own authorised stream URLs.
